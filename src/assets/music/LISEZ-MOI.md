# Musiques du launcher

Le launcher joue les musiques de Minecraft directement depuis les fichiers du jeu, que chaque joueur
télécharge chez Mojang en lançant une instance. Il n'y a donc rien à mettre ici pour que la musique
fonctionne chez les joueurs.

Ce dossier sert uniquement à ajouter des musiques à toi pendant tes essais sur ce PC :

- Formats acceptés : `.mp3`, `.ogg`, `.wav`, `.m4a`, `.flac`. Le nom du fichier devient le nom affiché.
- Les fichiers déposés ici ne sont **pas** envoyés sur GitHub (ils sont ignorés par git) : ils ne
  sont donc pas dans la version publiée par `/creer`, seulement dans tes compilations locales.
- Le dépôt étant public, c'est voulu : n'y publie que des musiques que tu as le droit de partager.
